Student Marks Predictor Using Linear Regression

📌 Project Description

The Student Marks Predictor is a simple Machine Learning project that uses Linear Regression to predict a student's marks based on the number of study hours.

This project uses Python to train a Linear Regression model with sample data. It provides a simple graphical user interface (GUI) using Tkinter, where users can enter their study hours and get predicted marks.

🎯 Objective

The main objective of this project is to understand and demonstrate the working of the Linear Regression algorithm through a real-world example.

🛠️ Technologies Used

- Python
- NumPy
- Scikit-learn
- Tkinter
- Linear Regression

⚙️ Features

- Predicts marks based on study hours.
- Uses a Linear Regression model.
- Simple and user-friendly graphical interface.
- Validates user input.
- Displays an error message for negative study hours or invalid input.

🧠 Algorithm Used: Linear Regression

Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values by finding the relationship between an input variable and an output variable.

In this project:

- Input (X): Number of study hours.
- Output (y): Student marks.
- Model: Linear Regression.

The model learns the relationship between study hours and marks using the sample dataset and predicts marks for the entered study hours.

📥 Installation

Step 1: Install Python

Download and install Python from "python.org" (https://www.python.org/).

Step 2: Install Required Libraries

Open Command Prompt or Terminal and run:

pip install numpy scikit-learn

Note: Tkinter is usually included with standard Python installations.

Step 3: Run the Program

Navigate to the project folder and execute:

python student_marks_predictor.py

💻 How to Use

1. Run the Python program.
2. The Student Marks Predictor window will open.
3. Enter the number of study hours.
4. Click the Predict Marks button.
5. View the predicted marks on the screen.
